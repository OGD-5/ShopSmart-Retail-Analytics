# ShopSmart Retail Analytics & AI Implementation Project

## Project Overview
This project is part of the AnalystLab Africa Experience Lab Internship Programme. The objective was to clean, analyze, and build an interactive Executive Performance Dashboard for ShopSmart Retail Ltd., a company operating multiple retail stores across Nigeria. 

The analysis identifies sales trends, inventory shortages, and product return patterns to provide actionable business recommendations.

## Tools & Techniques Used
- **Microsoft Excel:** Data Cleaning, Power Query, XLOOKUP/VLOOKUP
- **Data Modeling:** Entity Relationship mapping and Foreign/Primary Key establishment
- **Data Analysis:** Pivot Tables, Advanced Aggregations (KPIs)
- **Data Visualization:** Interactive Executive Dashboard with Report Connections (Slicers)

## Key Business Insights
1. **Regional Dominance:** The South Region generated the highest total revenue (₦2.42 Billion), largely driven by the ShopSmart Lagos branch.
2. **Category Performance:** The Beauty category drives the most top-line revenue, but Groceries follows closely behind with a much safer, lower return rate (4.57%).
3. **Inventory Risks:** Critical stockouts were identified in specific branches, with ShopSmart Enugu running dangerously low on stock.

## Final Deliverables Included in this Repository
- `ShopSmart_Analysis.xlsx`: The master Excel workbook containing cleaned data, pivot analysis, and the interactive dashboard.
- `Executive_Dashboard.pdf`: A high-resolution export of the interactive dashboard.
- `Business_Report.pdf`: A one-page executive summary detailing key findings, business recommendations, identified risks, and growth opportunities.
